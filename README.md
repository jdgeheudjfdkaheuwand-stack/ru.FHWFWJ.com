# GAMEHUB

Каталог игр и приложений со скачиванием. Обычный статический сайт (HTML + CSS + JavaScript) — без Node.js, npm, сервера и Firebase. Работает на GitHub Pages.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (New repository, например `GameHub`, Public).
2. Загрузите **содержимое** папки проекта (Add file → Upload files). Файлы `index.html`, `style.css`, `js/` и остальные должны лежать в корне репозитория. Не забудьте скрытые файлы `.nojekyll` и `.gitignore`.
3. Откройте Settings → Pages.
4. В блоке Build and deployment выберите Source: **Deploy from a branch**.
5. Ветка: **main**, папка: **/ (root)**.
6. Нажмите **Save**.
7. Через 1–2 минуты сверху появится ссылка вида `https://ВАШ-НИК.github.io/GameHub/`. Это адрес сайта.

Админ-панель: `https://ВАШ-НИК.github.io/GameHub/admin.html`

## Вход в админ-панель

Пароля администратора в коде нет — его создаёте вы.

1. Откройте `/admin.html`.
2. При первом запуске появится форма «Создание администратора». Придумайте логин и пароль (от 8 символов).
3. Нажмите «Создать и войти». Дальше на этой странице будет обычный вход по этому логину и паролю.

Логин и пароль хранятся в браузере в виде хэша (PBKDF2-SHA256 с солью), сам пароль нигде не сохраняется. Сменить пароль или удалить доступ можно во вкладке «Аккаунт».

## Как добавлять игры

Сами файлы игр в GitHub не хранятся. Загрузите файл в любое внешнее хранилище, которое отдаёт **прямую ссылку на скачивание** (свой сервер, S3-совместимое хранилище, файлообменник с прямыми ссылками), и вставьте ссылку в поле «Ссылка на файл». Так можно раздавать файлы и около 1 ГБ.

Ссылки в демонстрационных играх (`example.com`) нерабочие — замените их своими.

## Важно: как изменения увидят все посетители

GitHub Pages — статический хостинг. Всё, что вы меняете в админ-панели (игры, реклама), сохраняется в `localStorage` **вашего** браузера. Другие посетители этих изменений не видят.

Чтобы опубликовать каталог для всех:

1. Админ-панель → вкладка «Публикация» → «Скачать data.js».
2. В репозитории замените файл `js/data.js` скачанным (Edit или Upload files → Commit).
3. Через минуту каталог обновится у всех.

Импорт того же файла в админ-панель позволяет продолжить редактирование на другом устройстве.

## Безопасность (честно)

Этот проект — рабочая демонстрационная версия. `localStorage` — не серверная авторизация.

- **Аккаунты пользователей** хранятся только в браузере пользователя. Аккаунт, созданный на одном устройстве, не существует на другом. Логин «с другого телефона» невозможен.
- **Админ-панель** защищает вход только на уровне интерфейса. Любой человек может открыть `/admin.html` в своём браузере и создать собственного «администратора», но его правки увидит только он сам. Настоящих посетителей это не затрагивает: каталог для всех определяется файлом `js/data.js` в вашем репозитории, а изменить его может только владелец репозитория.
- **Статистика** (пользователи, скачивания) считается в каждом браузере отдельно.
- Не используйте на сайте пароли от важных сервисов.

### Что нужно для настоящей регистрации и админки

Общие аккаунты, единая статистика скачиваний и правка каталога через админ-панель без ручной замены файла требуют сервера (backend) с базой данных, где пароли хранятся в виде хэшей, а проверка прав выполняется на сервере. GitHub Pages этого не умеет. Когда понадобится такая версия, интерфейс из этого проекта можно оставить и подключить его к серверному API.

## Реклама

Админ-панель → «Реклама»: вставьте рекламный HTML-код, выберите места (между карточками, внизу страницы, перед скачиванием) и нажмите «Сохранить». Реклама выводится обычными блоками с пометкой «Реклама», без всплывающих окон и перекрытия меню. Чтобы реклама была видна всем, опубликуйте `data.js` (см. выше).

Код рекламных сетей выполняется на странице: вставляйте только код от проверенных сервисов.

## Структура

```
GameHub/
├── index.html      каталог
├── auth.html       вход и регистрация
├── admin.html      админ-панель
├── 404.html        страница «не найдено» для GitHub Pages
├── style.css
├── .nojekyll       отключает обработку Jekyll
├── .gitignore
└── js/
    ├── data.js     каталог и реклама по умолчанию (виден всем)
    ├── common.js   общие функции, SVG-иконки, хранилище
    ├── app.js      каталог, поиск, таймер скачивания
    ├── auth.js     регистрация и вход
    └── admin.js    админ-панель
```

Все пути относительные, поэтому сайт работает и в корне домена, и в подпапке `username.github.io/GameHub/`.

Шрифты (Manrope, Unbounded) подгружаются с Google Fonts; если они недоступны, сайт использует системные.
