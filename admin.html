Как показать изменения всем посетителям

GitHub Pages — статический хостинг без сервера, поэтому всё, что вы меняете здесь, сохраняется только в этом браузере. Посетители видят каталог из файла js/data.js в репозитории. Чтобы опубликовать изменения для всех:

  1. Нажмите «Скачать data.js».
  2. В репозитории на GitHub откройте js/data.js → значок карандаша (Edit) или загрузите файл поверх старого.
  3. Сохраните изменения (Commit). Через минуту сайт обновится у всех.

Импорт и сброс

Загрузите ранее сохранённый data.js или .json, чтобы продолжить редактирование на другом устройстве. «Сбросить» удалит локальные правки и вернёт каталог из js/data.js.
